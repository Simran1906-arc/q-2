# Regular Expression Matching

A web-based Regular Expression Matching tool using pattern matching algorithm.

## Live Demo

https://regression-matcher.netlify.app/

## Problem Statement

Given an input string P and pattern Q, implement regular expression matching where **+** means one or more of the preceding element. The matching should cover the entire input string.

## How to Run

Open the live link, enter a string P and pattern Q (uppercase letters only), and click Check Match.
